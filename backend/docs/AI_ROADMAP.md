# AI 진단 시스템 개선 로드맵

> 최종 업데이트: 2026-02-02

## 📊 현재 상황

| 항목 | 현재 상태 | 문제점 |
|------|----------|--------|
| **티어 판정** | 앵커 40장 비교 승률 기반 | 정확도 ~77% |
| **세부 점수** | 가짜 (승률에서 랜덤 변동) | 실제 평가 아님 |
| **대학 합격률** | 티어 기반 휴리스틱 | 실제 데이터 없음 |
| **피드백** | OpenAI LLM 생성 | 비용 발생, 실제 분석 아님 |
| **입력 검증** | 엣지/엔트로피 체크 | 완료 |

### 현재 모델 스펙
- **백본**: DINOv2-large (frozen, 304M params)
- **학습 파라미터**: 674K (Projector + ScoreHead)
- **학습 데이터**: ~2,000장 이미지, 20,000 페어
- **Val Accuracy**: 76.7%

## 🔴 논의 필요 사항

### 1. 세부 점수 (구도/색채/기법/창의성)

**현재**: 승률에서 랜덤 변동으로 생성 (가짜)

**옵션**:
- **A) 숨기기**: UI에서 세부 점수 제거, 티어만 표시
- **B) "참고용" 표시**: 세부 점수는 보여주되 "AI 추정치" 명시
- **C) 실제 개발**: Multi-task 모델로 각 항목별 점수 학습
  - 전문가 라벨링 데이터 필요 (비용/시간)
  - 예상 소요: 1-2개월

### 2. 모델 정확도 향상 방안

**현재 문제점**:
- 과적합 경향 (train loss << val loss)
- 데이터 품질 미검증 (라벨 오류 가능성)
- 앵커 선정이 랜덤

**개선 방안**:
- [ ] 데이터 품질 점검 (라벨 오류 수동 검토)
- [ ] Hard Negative Mining (어려운 샘플 집중 학습)
- [ ] 앵커 선정 개선 (랜덤 → centroid 기반)
- [ ] 모델 앙상블 (여러 체크포인트 평균)
- [ ] DINOv2 일부 레이어 fine-tuning (파라미터 증가)

### 3. 전체 로드맵 우선순위

**제안 순서**:
1. Phase 1 (단기): 기반 강화 - 정확도 85%+ 목표
2. Phase 2 (중기): 세부 평가 모델 개발
3. Phase 3 (중기): 신뢰성 강화
4. Phase 4 (장기): 대학별 예측

## 🗺️ 상세 로드맵

### Phase 1: 기반 강화 (1~2주)

**목표**: 티어 판정 정확도 85%+

- [ ] 데이터 품질 점검
  - 각 티어별 샘플 수동 검토
  - 라벨 오류 수정
- [ ] 앵커 선정 개선
  - 랜덤 → 각 티어의 centroid에 가까운 이미지 선정
  - 앵커 수 증가 (10 → 20장/티어)
- [ ] Hard Negative Mining
  - 경계선 샘플 (A/B, B/C 경계) 집중 학습
- [ ] 모델 앙상블
  - Top-3 체크포인트 평균
- [ ] UI 개선
  - 세부 점수 "참고용" 표시 또는 숨김

### Phase 2: 세부 평가 모델 (1~2개월)

**목표**: 실제 세부 점수 예측

**전제조건**: 전문가 라벨링 데이터

- [ ] 라벨링 가이드라인 작성
  - 구도, 색채, 기법, 창의성 각 항목 정의
  - 점수 기준 (1-100 또는 1-5)
- [ ] 라벨링 데이터 수집
  - 최소 500장 이상 전문가 라벨링
- [ ] Multi-task 모델 개발
  ```
  DINOv2 → Projector → [구도 Head]
                     → [색채 Head]
                     → [기법 Head]
                     → [창의성 Head]
                     → [티어 Head]
  ```
- [ ] 모델 학습 및 검증

### Phase 3: 신뢰성 강화 (1~2개월)

**목표**: 프로덕션 수준 안정성

- [ ] Out-of-Distribution (OOD) 감지
  - 작품이 아닌 이미지 (사진, 스크린샷 등) 거부
  - Feature space 거리 기반 감지
- [ ] Confidence Calibration
  - 예측 신뢰도가 실제 정확도 반영하도록 보정
- [ ] A/B 테스트 시스템
  - 모델 버전별 성능 비교
- [ ] 모니터링 대시보드
  - 일별 요청 수, 티어 분포, 에러율

### Phase 4: 대학별 예측 (3개월+)

**목표**: 실제 합격률 예측

**전제조건**: 실제 합격/불합격 데이터

- [ ] 데이터 수집
  - 사용자 동의 하에 진단 결과 + 실제 결과 매칭
  - 최소 대학당 100건 이상
- [ ] 대학별 예측 모델
  - 입력: 이미지 feature + 학과 + 대학
  - 출력: 합격 확률
- [ ] 연도별 업데이트 시스템
